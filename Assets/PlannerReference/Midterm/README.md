# 중간발표: 마을과 골목 조사 시연

시작 씬: `Scenes/Midterm_Town.unity`.
Unity 6000.6.4f1 / URP. 기존 Prototype과 PlannerReference 씬은 보존한다.
이번 시연은 전용 런타임으로 동작하며 기존 CharacterManager를 변경하지 않는다.

## 조작

- WASD 또는 방향키: 이동
- Tab: 같은 맵에 있는 여동생/오빠 전환. 위치를 맞바꾸지 않고 새 캐릭터가 선두가 된다.
- 마을 위쪽 ALLEY 길을 따라 걸어가면 골목으로 이동. 골목 아래쪽 출구로 마을 복귀
- 골목은 아래에서 올라와 오른쪽으로 꺾는 ㅏ형 동선. 상단 벽의 현장에 접근하면 첫 대화 시작
- 대화: E / Space / Enter 또는 다음 버튼. 화자는 대화창 좌측 위 이름표로 표시
- 쓰러진 사람 근처 E: 현장 관찰. 마우스 호버로 강조, 클릭으로 조사
- 조사 대사 종료: 관련 정보 ID 습득
- 관찰 중 E / Q / Esc: 부드럽게 탐색 시점 복귀
- 관찰 중에는 남매가 잠시 숨겨지고, 복귀하면 다시 표시된다. 조사 대상 강조는 물체 크기에 맞춘 테두리
- I 또는 화면 오른쪽 화살표: 정보 탭. 새 정보는 붉은 알림 표시
- R: 소지품 선택, 좌우: 선택 변경, R: 빈손에 장착, Q: 취소
- 좌우 끝: 연결된 별도 씬. 건너편은 빈 공간 더미

## 데이터와 범위

- 동생 index 0, 오빠 index 1. 기본 용량 5 / 6칸.
- 물건의 `slots`로 점유 칸 지정. `TryAddItem`에서 남은 칸 검사. 무게 제한 없음.
- 이번 현장 물건은 조사 대상이며 임의로 습득 가능하도록 만들지 않았다. 초기 소지품은 비어 있다.
- 카메라/녹음기 미소지: 정보 탭만 표시. `capturesEvidence` 물건 소지 시 증거 탭 표시 조건 제공. 실제 촬영 기능은 이번 범위에 포함되지 않는다.
- `Data/*.asset`은 정보 객체. `id`는 분기 키, `description`은 표시문, `place`/`incident`는 분류다.
- `Knows(actor, id)`로 대화 분기에서 지식 조회 가능.
- 동일 맵에 실제 존재하며 전환 가능한 두 사람만 함께 정보를 얻는다. 반복 조사는 중복 지급하지 않는다.
- 정보/장착 상태는 시연 씬 간 유지, 새 Play 세션에서는 초기화. 저장 파일을 쓰지 않는다.
- 대사와 정보 문장은 기획자 제공 원문을 사용했다. 사망·살해 추정 문구는 게임 내 서술이다.
- 개 짖는 소리는 교체 가능한 합성 더미 WAV. 최종 음원이 아니다.
- UI는 픽셀 테두리 더미. 게임 화면만 640x360 Point 렌더링, UI는 별도 표시.
- 캐릭터는 앞쪽 얼굴 표시/뒤쪽 등 표시가 있는 단순 3D 도형 더미. 이동 방향으로 연속 회전하며 다리가 움직인다.
- 탐색 카메라 40도/확대 5.6, 조사 카메라 12도/확대 2.65. 전경에서 캐릭터 또는 조사 중심을 가리는 벽만 부드럽게 투명해진다.
- 마을 입구의 밝은 바닥 표시는 제거. 현장 골목 폭 8, 남자는 벽에 기대어 두 다리를 뻗은 형태.

## 검증과 편집

`OTK > 중간발표 > 시연 씬 구조 검증`으로 씬/데이터 연결을 검사한다.
`MidtermPlayCheck.Run` 배치 검사는 플레이 모드에서 지식, 전환, 칸 제한, 카메라 복귀, 씬 전환을 확인한다.
씬 생성 메뉴는 이 폴더의 세 씬을 재생성하므로 수동 배치 수정 후에는 실행하지 않는다.
원본 개발 씬에 통합할 때 필요한 데이터/로직만 선별해서 사용한다.
